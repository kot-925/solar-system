# Солнечная система — 3D

Интерактивная реалистичная модель Солнечной системы в браузере (Three.js, WebGL).

**Открыть онлайн:** https://kot-925.github.io/solar-system/

## Запуск

Текстуры нельзя загрузить через `file://`, поэтому нужен локальный сервер:

```
python3 -m http.server 8000
```

Откройте http://localhost:8000. Нужен интернет для загрузки Three.js с CDN (jsDelivr).

## Без сервера

`solar-system.html` — автономная версия: код и текстуры встроены в файл, открывается двойным кликом
(нужен только интернет для Three.js). В ней 2K-текстуры и 8K-небо, без подгрузки 8K по требованию.
Пересобрать после изменений:

```
python3 build_standalone.py
```

## Что внутри

- **Реальные положения планет на текущую дату**: кеплеровы элементы JPL (J2000), эллиптические наклонённые орбиты.
- **Реальная ориентация и вращение** по данным IAU: наклоны осей, обратное вращение Венеры и Урана, сплюснутость планет, Луна всегда повёрнута к Земле одной стороной.
- **Земля**: дневная карта, рельеф (normal map), блики только на воде, огни городов на ночной стороне, облака с тенями, атмосфера с закатным оттенком у терминатора.
- **Сатурн**: кольца с тенью на планете и тенью планеты на кольцах.
- **Солнце**: анимированная грануляция, потемнение к краю, корона, bloom.
- Спутники: Луна, Фобос, Деймос, Ио, Европа, Ганимед, Каллисто, Титан; пояс астероидов и пояс Койпера.
- **Наглядный / реальный масштаб** с плавным переходом (в реальном — истинные размеры и расстояния).
- 8K-текстуры подгружаются для выбранного тела и выгружаются при смене фокуса.

## Управление

Перетаскивание — вращение, колесо — масштаб, ПКМ — сдвиг, клик по телу или подписи — перелёт к нему.
Пробел — пауза, Esc — обзор. Внизу — скорость времени, обратный ход, кнопка «Сейчас».
